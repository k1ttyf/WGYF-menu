# k1ttyf/WGYF-menu

`CasinoMenu` 0.1.0 — BepInEx 5 Mono-плагин с OnGUI-меню. Использует игровые классы, Mirror, Harmony и Unity Input System. Основной файл — `src/CasinoMenuPlugin.cs`; интерфейс — `CasinoMenuInterface.cs`, прогрессия — `CasinoMenuProgression.cs`, мир — `CasinoMenuWorld.cs`, общие функции — `CasinoMenuHelpers.cs`.

Для реализации изучены метаданные и IL установленной `Assembly-CSharp.dll` Инструмент статического анализа: `tools/InspectAssembly.cs`, подробные дампы: `analysis/scan-dumps.zip`.

## Управление

По умолчанию **Insert** открывает меню. Существующий конфиг сохраняет ранее выбранную клавишу. **Keybinds** содержит поиск, переназначение переключателей и основных действий. Переключатели привязываются к одной клавише. Для действий с сочетаниями сначала удерживайте модификатор, затем нажмите основную клавишу; Escape отменяет переназначение.

| Клавиша | Действие по умолчанию |
| --- | --- |
| F4 | Переключить noclip |
| F6 | Победа за ближайшим столом |
| F7 / F8 | Добавить / убрать 1000 денег |
| F9 | Добавить 10 билетов |
| F10 | Добавить недостающие до квоты деньги |
| F11 | Восстановить органы |
| Space / Left Ctrl | Вверх / вниз в noclip |

Escape закрывает открытое меню. **Settings → Reset input layer** возвращает ввод игре. Там же видны слой ввода, нажатые клавиши, курсор и noclip; можно включить запись статуса в лог.

## Функции

| Раздел | Реализованные действия |
| --- | --- |
| Day | Длительность дня, пауза, добавление/удаление времени, завершение дня, произвольное число оставшихся дней, бесконечные дни, скорость игры |
| Money | Добавить/убрать/задать баланс через BigNumber, кнопки до квадриллиона, автоденьги, закрытие квоты деньгами, возврат расходов, множитель выигрыша, долг, сброс балансов, билеты |
| Bailout | При нулевом балансе во время дня выдать выбранную долю квоты, один раз за игровой день |
| Quota | Множитель текущей и будущих квот, ручное значение квоты и требования следующего этажа, завершение квоты, переход этажа, блокировка Lose |
| Floors | Открыть кнопки лифта, запретить перемещение, отправить лобби на существующий этаж |
| Players | Индивидуальные и групповые блокировка движения, ragdoll, пробуждение, отбрасывание, выброс предмета, лечение, телепортация; исключение других игроков; эффекты органов и блокировка головы |
| Items | Поиск и создание из SpawnableSettings, удаление оружия/предметов, обезвреживание бит и тазеров, сброс предметов/штампов, выброс/удаление удерживаемого |
| Perks | Выдать/очистить Tipsy Fortune, Inspiring Melody, Immunity; заполнить/убрать энергию, изменить/сбросить улучшения всех игроков |
| Self | Восстановить органы, множители движения/прыжка, локальный noclip, победа/поражение за ближайшим столом в пределах 8 метров |
| Game | Игровые состояния/сцены, сохранение/загрузка/сброс, приватность, лимит игроков, приглашение, NPC, катсцена по индексу, seed и показатели |
| Advanced | NPC count, days per quota, daily tickets, catch-up factor, starting money/tickets/quota, восстановление исходных правил; каталог испытаний с поиском/фильтром этажа, активация, завершение и награды |

Деньги вводятся в формате игрового `BigNumber.Parse`. Билеты и стартовые значения ограничены целочисленными типами игры. Множитель noclip `x0.5…x10` применяется к исходному `PlayerSettings.maxSpeed`, независимо от множителя обычного движения. Используются штатные включение/выключение noclip и переназначенный игровой ввод; интеграция движения заменена, чтобы скорость соответствовала базовой без зависимости от игрового сглаживания.

## Настройки сохранений

**Advanced → Per-save rules** хранит правила прогрессии, таймера, скорости игры и валюты отдельно для имени каждого сохранения в секциях `SaveRules.*` конфига плагина. Глобальные значения находятся в `GlobalRules.*`. Новое сохранение получает глобальные правила. При выключении функции используются глобальные правила. Клавиши, движение и World остаются общими.

При загрузке старого профиля без данных о масштабировании текущая квота не умножается повторно. Дальнейшее изменение множителя применяется сразу, новые квоты масштабируются штатно. Старые экспериментальные секции с заменой пробелов/пунктуации на `_` автоматически не мигрируются из-за возможного совпадения имён.

## Сборка и установка

Нужны установленная игра, BepInEx 5 Mono и компилятор C# из Visual Studio/Build Tools. Пути и ссылки на библиотеки заданы в `build.ps1`. Новых зависимостей для плагина нет.

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\build.ps1
```

Результат: `dist\CasinoMenu.dll`. Скрипт пытается скопировать DLL в:

```text
C:\Program Files (x86)\Steam\steamapps\common\Gamble With Your Friends\BepInEx\plugins\CasinoMenu
```

Если Windows запрещает запись, DLL остаётся в `dist`. Закройте игру, создайте указанную папку и скопируйте туда DLL от имени администратора. Избегайте одновременной загрузки других меню, меняющих те же методы.

Конфиг: `BepInEx\config\com.wdyf.menu.cfg`. Лог: `BepInEx\LogOutput.log`.

## Ограничения и проверка

- Серверные действия требуют `NetworkServer.active`. На клиенте доступен штатный запрос создания предмета через `NewConsole.RequestSpawnPrefab`; результат зависит от сервера и игровых проверок.
- Штатный noclip доступен только локальному игроку. Удалённый noclip всем участникам без дополнительного клиентского кода не реализован.
- «Без рта» включает игровой эффект голоса, а не отключение голосового чата. Ауры могут повторно наложить очищенный перк.
- Лимит игроков: 1–16; изменение платформенного лимита зависит от доступности штатного API. Индексы катсцен должны существовать в игре.
- После обновления игры может потребоваться адаптация и пересборка. При ошибке установки Harmony-патчей изменения плагина откатываются; проверки номера сборки игры нет.
- Load перечитывает текущий слот с диска; Reset сразу применяет исходные данные. Штатная загрузка восстанавливает баланс, прогрессию, правила, органы, улучшения и список предметов. Физические объекты обновляются при следующей смене сцены; состояние текущего таймера полностью не восстанавливается.
- Компиляция выполнена без ошибок и предупреждений компилятора. Статическая проверка `tools/ValidatePatches.cs` подтвердила 26 целей Harmony и 32 инъекции параметров, ошибок нет. Проверка в запущенной игре **не выполнена**; установка в Program Files запрещена Windows.
